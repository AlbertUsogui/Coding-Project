Explore the projects developed by our Computer Science members, showcasing the practical application of programming concepts and problem-solving skills. Our collection includes a variety of projects ranging from simple programs designed to strengthen fundamental skills to more complex applications that demonstrate creativity, logical thinking, and technical knowledge. Each project represents an opportunity to experiment with new ideas, apply what we have learned, and develop solutions through programming.

Our Recent Projects

Rock paper scissor

An interactive game where the player competes against the computer by choosing rock, paper, or scissors. The computer randomly selects its own choice, and the program compares both choices to determine the winner. The game demonstrates the use of conditional statements, randomisation, user input, input validation, variables, and loops. Players can continue playing multiple rounds while keeping track of their score, making the game more interactive and engaging.

Code Breaker

An interactive puzzle game where players attempt to crack a hidden code using clues and logical reasoning. Each round presents a different code for the player to solve, with feedback provided after each attempt. The game demonstrates the use of loops, conditional statements, input validation, randomisation, and logical problem-solving.

Turnfall

Turnfall is a turn-based battle game where players fight an enemy by choosing different actions during each turn. Players can attack to deal damage, heal to restore health, or use a limited number of potions when their health is low. After each player turn, the enemy attacks back, requiring players to think carefully about their decisions and manage their health. The goal is to defeat the enemy before losing all health. The game demonstrates variables, functions, selection, iteration, randomisation, user input, and input validation in Python.

Compatibility Game

An interactive quiz that estimates how compatible two people might be based on their answers to a series of questions about personality, preferences, communication, and relationships. The program calculates a compatibility score and provides a fun result based on the answers. It demonstrates the use of user input, variables, selection, calculations, validation, and conditional logic while creating an engaging and interactive experience.

Maze Game

Maze Game is an interactive game where the player must navigate through a maze and reach the goal while avoiding walls and finding the correct path. The player can move using simple keyboard controls such as W, A, S, and D, with each movement updating their position within the maze. The game keeps track of the number of moves made and prevents the player from moving through walls. It demonstrates important Python programming concepts such as 2D arrays, functions, loops, selection, user input, indexing, variables, and input validation, making it a suitable AS-Level programming project.

Linear Search

A simple searching algorithm that checks each item in a list one by one until the desired value is found or the end of the list is reached. The project demonstrates how iteration, conditional statements, lists, variables, and input can be used to efficiently search through a collection of data.

Fortune Teller

The Fortune Teller Game is an interactive Python program that generates random fortunes for users. It features a menu with five options: Good Fortune, Bad Fortune, Random Fortune, How to Play, and Exit. Users can choose to receive a positive prediction, a spooky prediction, or a randomly selected fortune from a collection of ten fortunes. The program uses random selection, variables, lists, loops, and conditional statements to create an engaging experience. It also includes input validation to handle invalid menu choices and allows users to continue playing until they decide to exit. The fortunes are fictional and intended for entertainment purposes only.

Bubble Sort

A sorting algorithm that arranges a collection of values into a specific order by repeatedly comparing adjacent elements and swapping them when they are in the wrong order. The algorithm continues making passes through the list until no more swaps are needed, meaning the data is fully sorted. This project demonstrates the use of nested loops, lists, conditional statements, variables, and comparison operators. It also helps illustrate how sorting algorithms work step by step.

Encryption

A program that converts readable messages into an encoded format using an encryption method, making the original message harder to understand without the correct key or process. Users can enter a message, encrypt it, and then decrypt it to recover the original text. The project demonstrates the use of strings, variables, loops, functions, and conditional statements while introducing the basic concepts of data security and encryption.

Unit Converter

A program that converts values between different units, such as length, weight, temperature, and time. Users can enter a value and select the units they want to convert between. The project demonstrates the use of variables, mathematical calculations, functions, user input, and input validation.

Password Generator

A program that creates random and secure passwords based on the user's chosen length and character types. It can combine uppercase and lowercase letters, numbers, and special characters to generate different passwords. The project demonstrates randomisation, strings, loops, variables, and user input.

Calculator

An interactive calculator that allows users to perform common mathematical operations such as addition, subtraction, multiplication, and division. The program takes user input, performs the selected calculation, and displays the result. It demonstrates variables, functions, selection, calculations, and input validation.

Stack ( ADTs )

A program that demonstrates the Stack data structure, where the last item added is the first item removed (LIFO). Users can add, remove, and view items in the stack. The project demonstrates lists, functions, iteration, and the fundamental operations of a stack.

Queue ( ADTs )

A program that demonstrates the Queue data structure, where the first item added is the first item removed (FIFO). Users can add items to the queue and remove them in the order they were added. The project demonstrates lists, functions, iteration, and the basic principles of queue management.

2D Arrays

A program that demonstrates how two-dimensional arrays can be used to store and organise data in rows and columns. Users can create, access, modify, and search through values within the array. The project demonstrates nested lists, nested loops, indexing, and data organisation.
